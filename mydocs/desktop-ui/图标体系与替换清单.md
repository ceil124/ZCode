# 图标体系与替换清单

- 入口：`../README.md`。
- 结构与位置：`架构与文件地图.md`。
- 权威视觉规范：仓库根 `DESIGN.md`。

覆盖品牌图形、安装包/窗口/任务栏/托盘图标、`public/` 素材、界面功能性图标、运行时读取的外部应用图标。第三方图标库本体（`lucide-react`、radix 内部图标）不在本清单内，只受 `Root.tsx` 的 `LucideProvider` 默认线宽影响。

## 1. 品牌图形（Z 字形）

同一品牌语义存在 **4 份独立实现**，换品牌必须全部同步。

| # | 位置 | 形态 | 消费方 |
| --- | --- | --- | --- |
| 1 | `packages/ui/src/assets/provider-icons/logo-zai.svg` | 圆角底板 + 白 Z | `packages/ui/src/App.tsx:50`（作为 `appLogoUrl` 传给 `WorkspaceShellLayout` → `DesktopTopOverlay` 左上角 logo）、`packages/ui/src/WorkspaceSidebar/WorkspaceSidebarCollapsedRail.tsx:2`（侧栏收起态）、`packages/ui/src/WindowsTopLeftLogo.tsx:2`（Windows / 设置页左上角） |
| 2 | `packages/desktop/src/renderer/index.html`（约 118–136 行） | 纯字形内联 `<svg>` | 启动壳 logo（`#loading` 层） |
| 3 | `packages/desktop/src/main/aboutWindow.ts`（约 174–192 行） | 纯字形内联 `<svg>`，拼进 HTML 字符串 | About 对话框 |
| 4 | `packages/ui/src/components/ui/ZCodeAboutLogo.tsx` | 纯字形 React SVG 组件 | 设置页「关于」 |

第 1 项为**带底板**的品牌图块；第 2/3/4 项为**无底板字形**，三者 path 数据完全相同（`viewBox="0 0 256 218"`，三条 path）。改字形时必须同时改这 4 处，没有任何单一数据源。

`packages/ui/src/assets/provider-icons/` 下其他品牌图形：

| 文件 | 用途 |
| --- | --- |
| `logo-zai-square.svg` | Z.AI 方形变体 |
| `logo-bigmodel.svg` | BigModel OAuth 入口 |
| `logo-anthropic.svg` / `logo-openrouter.svg` / `logo-moonshoot.svg` | Provider 相关入口 |

`packages/ui/src/lib/oauthProviderIcon.tsx` 维护 `OAuthProviderId` → 图标映射，新增 OAuth 渠道需同步该表。

## 2. 应用图标（安装包 / 窗口 / 任务栏 / 托盘）

资产全部位于 `packages/desktop/build/`。

> **仓库内没有图标生成脚本。** `@fiahfy/icns` 只是打包期依赖完整性校验项（见 `packages/desktop/scripts/bundle.mjs:646`），不参与生成。`.icns` / `.ico` / 多档 PNG 必须离线生成后提交。

### 2.1 资产清单

| 资产 | 用途 | 引用点 |
| --- | --- | --- |
| `build/icon.icns` | macOS `.app` 图标 | electron-builder 自动探测（`directories.buildResources: "build"`，`electron-builder.config.js:484`；`mac` 段未显式指定 `icon`） |
| `build/icon.ico` | Windows 应用图标 | 同上（`win` 段未显式指定）；另拷为 `resources/tray_icon.ico` |
| `build/icon.png` | 非 Windows 运行时窗口图标 | `electron-builder.config.js:595` → `resources/icon.png` |
| `build/icon_windows.png` | Windows 窗口 / 任务栏图标 | `electron-builder.config.js:609` → `resources/icon_windows.png` |
| `build/icons/{16,24,32,48,64,128,256,512,1024}x*.png` | Linux 图标集 | electron-builder 自动探测 `build/icons/` |
| `build/icons/512x512.png` | Linux hicolor 用户级图标 | `electron-builder.config.js:602` → `resources/icon_512x512.png` |
| `build/icon_installer.icns` | DMG 卷图标 | `dmg.icon`（`electron-builder.config.js:738`） |
| `build/icon_installer.ico` | NSIS 安装 / 卸载 / 头部图标 | `nsis.installerIcon` / `uninstallerIcon` / `installerHeaderIcon` |
| `build/dmg_background.png`、`@2x` | DMG 背景 | `dmg.background`（同批素材，非图标） |

`extraResources` 拷贝规则见 `packages/desktop/electron-builder.config.js:593–621`。

### 2.2 运行时链路

| 环节 | 文件 |
| --- | --- |
| `iconPath` / `linuxDesktopIntegrationIconPath` 解析（区分 dev / packaged） | `packages/desktop/src/main/index.ts:280–293` |
| 窗口与对话框图标注入 | `packages/desktop/src/main/index.ts:318 / 1340 / 1581 / 1675 / 2222` |
| macOS Dock 图标 | `packages/desktop/src/main/desktopWindowChrome.ts` → `applyAppIcon()` |
| Windows AUMID / 任务栏图标 | `packages/desktop/src/main/windowsAumidIcon.ts` + `packages/desktop/scripts/desktop-product-identity.mjs` 的 `resolveWindowsAppUserModelIdForFlavor` |
| Linux 桌面集成图标 | `packages/desktop/src/main/desktopLinuxAppImageIcon.ts`（写 `~/.local/share/icons/hicolor/512x512/apps/zcode.png`；文件名由 `LINUX_APP_ICON_NAME = "zcode"` 固定） |

dev 与 packaged 路径差异全部集中在 `main/index.ts:280–293`，改图标不涉及代码改动，除非要新增图标种类。

## 4. 界面功能性图标

| 类别 | 位置 | 替换方式 |
| --- | --- | --- |
| Lucide 图标 | 全仓直接 `import`。默认线宽由 `packages/ui/src/Root.tsx` 的 `LucideProvider strokeWidth={1.5}` 统一 | 通常不改；改线宽改 `Root.tsx` |
| 自绘 Lucide 变体 | `packages/ui/src/components/icons/windowIcons.ts`（`WindowMaximizeIcon`、`WindowRestoreIcon`） | 改 path `d` |
| 窗口控制按钮 | `packages/ui/src/DesktopWindowControls.tsx`、`packages/ui/src/windowCaptionControls.ts` | 改组件 |
| Provider 品牌 logo | `packages/ui/src/assets/provider-icons/`（含来源与规范化说明 `model-provider-logo-sources.json`） | 替换文件并**同步该 JSON**（内含 sourceUrl / normalization，属素材溯源记录）。消费方：`settings/model-provider-section/ProviderLogo.tsx`、`lib/providerCliIcon.tsx`、`components/ui/GlmMonochromeIcon.tsx`、`lib/oauthProviderIcon.tsx` |
| 插件图标 | `packages/ui/src/assets/plugin-icons/` + `packages/ui/src/lib/pluginIconSource.ts` | 替换文件 + 改 `OFFICIAL_PLUGIN_ICON_BY_ID` 映射（key 为完整 pluginId，如 `documents@zcode-plugins-official`） |
| 技能图标 | `packages/ui/src/assets/document-skill-icons/` | 替换文件。消费方 `settings/PluginStoreDetailView.tsx`、`v4/featureSuggestedPrompts.ts` |
| 文件类型图标 | `packages/desktop/src/renderer/public/material-icons/`（1146 个 SVG，来自 vscode-material-icon-theme，MIT）。路径在 `packages/ui/src/lib/fileDisplay.tsx:43–57` 由 `import.meta.env.BASE_URL` 拼成 `material-icons/<name>.svg`；扩展名 → 图标名映射在 `packages/ui/src/lib/fileDisplayHelpers.ts`；兜底为内联 data URL（`INLINE_FALLBACK_FILE_ICON_SRC`） | 整体替换图标集需同步 `THIRD-PARTY-NOTICES.md` 的 Material Icon Theme 条目 |
| CLI 图标 | `packages/ui/src/assets/cli-icons/` | 替换文件 |
| 支付渠道图标 | `packages/ui/src/assets/payment-icons/` | 替换文件 |
| 通知音（同类素材） | `packages/ui/src/assets/notification-sounds/` | 替换文件 |
| 外部应用图标（运行时读取，**非内置**） | `packages/desktop/src/main/applicationIcons.ts`、`main/editors.ts`、`ui/src/lib/cuaAppIconRequest.ts` | 无需替换；macOS 读 bundle id、Windows 读 exe 路径或 AUMID |
| CUA 权限浮窗图标 | `packages/desktop/src/main/cuaPermissionDragPanel.ts` 的 `getIconDataUrl` → `platform.getApplicationIcon` | 无需替换 |

文件类型图标路径解析注意：`ui/src/lib/fileDisplay.tsx` 明确基于运行时 base URL 拼装（Web 挂根路径，Desktop 是 `file://` + `base="./"`），不要写死 `/material-icons`。

## 6. 换品牌执行清单（按顺序）

1. 生成并替换 `packages/desktop/build/` 全部图标资产：`.icns`、`.ico`、9 档 PNG、`icon.png`、`icon_windows.png`、`icon_installer.icns`、`icon_installer.ico`。
2. 同步第 1 节 4 处品牌图形（2 处内联 SVG + 1 处 React 组件 + 1 处 Vite 资源）。
3. 替换 `public/logo/icons/*` 与 `public/icon_512@2x.png`。
4. 替换 `packages/web/index.html` 内联 favicon。
5. 若涉及产品名：`packages/desktop/scripts/desktop-product-identity.mjs` 的 `productName` / `linuxExecutableName` / `appId` / AUMID；Preview flavor 需同步。
6. 若整体替换文件类型图标集：更新 `THIRD-PARTY-NOTICES.md` 与 `packages/desktop/electron-builder.config.js` 的 `extraResources`。
7. 校验：`pnpm build` 后确认打包产物 `resources/` 下存在 `icon.png`、`icon_windows.png`、`icon_512x512.png`、`tray_icon.ico`。

## 7. 常见误改点

| 现象 | 原因 |
| --- | --- |
| 换了 `logo-zai.svg`，启动画面 / About 还是旧图标 | 那两处是内联 SVG，不读资源文件 |
| 换了 `build/icon.png`，Windows 任务栏还是旧图标 | Windows 走独立的 `icon_windows.png` |
| 换了应用图标，托盘还是旧图标 | 托盘在 packaged 态读 `resources/tray_icon.ico`（来自 `build/icon.ico`），与窗口 PNG 解耦 |
| macOS 改了图标但 Dock 未变 | `applyAppIcon()` 只在 `process.platform === "darwin"` 且非 packaged 路径下生效；打包态由 `.icns` 决定，需重新打包 |
| 改了 `material-icons/` 下某文件但不生效 | 该目录属 Vite `public/`，按原文件名直出；改扩展名映射要同时改 `fileDisplayHelpers.ts` |
