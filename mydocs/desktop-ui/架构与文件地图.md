# 架构与文件地图

- 入口：`../README.md`。
- 权威视觉规范：仓库根 `DESIGN.md`（令牌、字号、圆角、间距、动效）。
- 权威架构约束：仓库根 `AGENTS.md`（进程边界、状态所有者、平台抽象）。
- 只描述结构与位置，不重复 `DESIGN.md` 的取值规则；单个功能点的改造细节见同目录专题文档。

章节划分：第 1–5 节为运行时结构（进程 → 启动 → 窗口 → chrome → 布局），第 6–9 节为前端分层（组件 → 样式令牌 → 平台抽象 → i18n），第 10 节为改造影响面速查。

## 1. 进程与产物分层

桌面端 UI 不是单一前端应用，而是由 5 类产物协作。

| 产物 | 源入口 | 构建 | 输出 | 职责 |
| --- | --- | --- | --- | --- |
| Main | `packages/desktop/src/main/index.ts` | tsup（esm / node22） | `out/main/index.js` | 窗口、原生菜单、托盘、IPC、进度与权限窗口、进程调度 |
| Preload | `packages/desktop/src/preload/index.ts` | tsup（cjs） | `out/preload/index.cjs` | `contextBridge` 暴露 `window.zcode`；MessagePort 转发 |
| Renderer | `packages/desktop/src/renderer/index.html` → `src/main.tsx` | Vite + React 19 | `out/renderer/` | 全部 UI |
| Host | `packages/desktop/src/host/index.ts` | tsup（esm） | `out/host/index.js` | 每窗口一个 `utilityProcess`，承载本地 workspace 服务与 Agent |
| Scheduler | `packages/desktop/src/scheduler/index.ts` | tsup（esm） | `out/scheduler/index.js` | 常驻 cron / 闲时调度 |

构建配置：`packages/desktop/tsup.config.ts`（main / preload / host / scheduler 四组 config）、`packages/desktop/vite.config.ts`（renderer）、`packages/desktop/electron-builder.config.js`（打包）。
TS 分片配置：`tsconfig.main.json`、`tsconfig.preload.json`、`tsconfig.renderer.json`、`tsconfig.host.json`、`tsconfig.scheduler.json`。

**Renderer 不包含 UI 主体。** `packages/desktop/src/renderer` 仅有 3 个 HTML 页面、4 个独立页面脚本与 `src/` 下 10 个启动/桥接文件；UI 组件全部来自 `packages/ui`，由 Vite 别名解析：

```
"@" -> packages/desktop/../ui/src      // vite.config.ts resolve.alias
```

因此修改 UI 的唯一正确位置是 `packages/ui/src`；`packages/desktop/src/renderer` 只改启动流程与平台桥。

## 2. Renderer 启动序列

`src/renderer/index.html`

- 静态启动壳：`#loading` 层 + 品牌 logo 弹入动画（`startup-logo-pop`，`prefers-reduced-motion` 降级）。
- 退场条件为「动画结束」且「React 首次 commit」，React 通过 `zcode-react-startup-ready` 事件回报；两条件都满足才加 `body.zcode-startup-ready`。
- `windowKind=update-status` 时跳过启动壳。
- 主入口 `<script type="module" src="./src/main.tsx">` 为静态引用，禁止改为动态 import（失败会永久停在 HTML loading）。

`src/renderer/src/main.tsx` 顺序：

1. `startPerformanceTimelineCleanup()`、解析 `LAUNCH_MARKS_QUERY_KEY` 启动分段耗时（T0–T5）。
2. 主题预置：读 `localStorage["zcode-theme"]`，默认 `zai-dark`；写 `html.dark` / `theme-zai-light` / `theme-zai-dark`。
3. 平台根标记：`platform-mac-desktop` / `platform-windows-desktop` / `platform-linux-desktop`。
4. `createDesktopPlatform({ isLocalDevelopmentRuntime })`（`src/renderer/src/desktopPlatform.ts`）。
5. 数据库启动门禁 `DatabaseStartupAdmission`：未就绪渲染 `GlobalDatabaseStartupLoading`；30s 未收到状态则失败态。
6. 收到 `InternalChannels.ServicePort` 后 `initializeBusinessRoot(port)`：`connectViaMessagePort` → `registerBaseWorkspaceServices` → 渲染 `Root`。
7. `windowKind === "update-status"` 时改为渲染 `UpdateStatusWindowRoot`（`@zcode/ui`）。

窗口参数经 URL query 注入（`src/main/desktopHostProcess.ts` 的 `loadWindow`）：`restoreSession`、`supportsSettings`、`initialWorkspacePath`、`initialWorkspacePurpose`、`unavailableWorkspacePath`、`windowKind`、`locale`、launch marks。

## 4. 窗口 Chrome 与平台差异

`src/main/desktopWindowChrome.ts` → `buildDesktopWindowVisualOptions()` 定义三平台外观：

| 平台 | BrowserWindow 参数 |
| --- | --- |
| macOS | `backgroundColor: #00000000`、`titleBarStyle: "hidden"`、`trafficLightPosition: {x:22,y:23}`、`vibrancy: "under-window"` |
| Windows | `backgroundColor: #00000000`、`frame: false`、`backgroundMaterial: "acrylic"`；窗口控制由 renderer 自绘 + `setTitleBarOverlay` |

## 5. 布局骨架（Workspace Shell）

唯一布局实现：`packages/ui/src/app-shell/WorkspaceShellLayout.tsx`（memo 组件，集中编排，文件内标注 `eslint-disable max-lines`）。

嵌套结构：

```
DesktopWindowFrame                              // 窗口外壳
└─ div[data-workspace-shell]                    // flex row
   ├─ div#sidebar[data-workspace-sidebar-panel] // 侧栏，宽度由 CSS 变量驱动
   │  └─ aside > ScopedErrorBoundary > WorkspaceSidebar
   ├─ div[role=separator][data-testid=resizable-handle]  // 侧栏拖拽手柄
   └─ div#content                               // min-width 320px, flex-1
      ├─ div.h-1[app-region:drag]               // 仅桌面有 inset 时的顶部拖拽带
      ├─ ResizablePanelGroup "workspace-body-layout" [conversation-column, browser]
      │  ├─ ResizablePanel#conversation-column
      │  │  └─ ResizablePanelGroup "workspace-conversation-column-layout" [conversation, terminal]
      │  │     ├─ ResizablePanel#conversation
      │  │     │  └─ section[data-workspace-conversation-frame]
      │  │     │     ├─ WorkspaceHeader
      │  │     │     └─ V4WorkspaceChatArea
      │  │     └─ ResizablePanel#terminal → AnimatedTerminalPanel
      │  └─ ResizablePanel#browser → AnimatedSidePanePanel
      └─ DesktopTopOverlay                      // 绝对定位浮层
```

| 任务列表 | `TaskList` 系列 | `packages/ui/src/TaskList.tsx`，`TaskListItem.tsx`，`TaskListItemContextMenu.tsx`，`workspace-grouped-tasks/`，`WorkspaceGroupedTasksSection.tsx` |

侧栏宽度与面板尺寸：

- 侧栏宽度常量在 `WorkspaceShellLayout.tsx` 顶部：`WORKSPACE_SIDEBAR_DEFAULT_WIDTH_PX = 264`、`MIN = 264`、`MAX_RATIO = 0.5`、键盘步进 `16px`。
- 持久化 key：`zcode:workspace-shell:sidebar-width-px`；CSS 变量 `--workspace-sidebar-panel-width`、`--workspace-sidebar-width`。
- 侧栏宽度走 CSS 变量 + DOM 标记（`data-workspace-sidebar-resizing`），拖拽期不写 React 状态，避免整棵 workspace 重渲染。
- 自动收起阈值：`CONVERSATION_AUTO_COLLAPSE_SIDE_PANE_WIDTH_PX = 480`、`CONVERSATION_AUTO_COLLAPSE_SIDEBAR_WIDTH_PX = 360`、`CONVERSATION_AUTO_COLLAPSE_RESIZE_IDLE_MS = 300`。
- 右侧面板默认展开尺寸：`app-shell/sidePaneLayout.ts` 的 `SIDE_PANE_DEFAULT_EXPANDED_SIZE`。
- 面板动画与受控 resize：`app-shell/useAnimatedResizablePanel.ts`。
- 会话 frame / terminal / side pane 共用的 `--workspace-panel-radius` 由 `resolveWorkspaceShellPanelRadiusPx()` 计算（Windows 5px；macOS ≥26 为 12px，否则 6px；Linux 12px）。

改造注意：panel id 数组 `WORKSPACE_BODY_PANEL_IDS`、`WORKSPACE_CONVERSATION_PANEL_IDS` 必须是模块级常量，`ResizablePanelGroup` 收到新引用会重算布局。

## 7. 样式与设计令牌

`packages/ui/src/styles.css` 是唯一全局样式入口，由 renderer 通过 `import "@zcode/ui/styles.css"` 引入。

| 区块 | 行 | 内容 |

| `@theme` | 137–307 | 浅色默认令牌：字体栈、`--text-ui-*`、`--color-*` 语义色 |
| `.dark` | 308–460 | 暗色默认令牌 |
| `.theme-zai-light` | 461–605 | 产品浅色主题（用户可见的 Light Theme） |
| `.theme-zai-dark` | 606–812 | 产品暗色主题（默认主题） |
| `@layer utilities` | 813– | 工具类 |

字号体系（`DESIGN.md` 规定为仓库级强制约束）：

- 所有界面文字必须使用 `text-ui-xl` / `text-ui-lg` / `text-ui-base` / `text-ui-caption` / `text-ui-sm` / `text-ui-xs`。
- 禁止 Tailwind 内建 `text-base` / `text-sm` / `text-xs`，禁止 `text-[13px]` 或内联 `font-size`。
- `text-ui-2xs` 仅限工作流图轴面刻度；`text-mobile-input-safe`（16px）仅限移动 Web 防 iOS 缩放。
- 界面缩放只改 `--ui-font-size`，禁止改 `html` 根字号。

字号运行链路：`packages/ui/src/lib/uiFontSize.ts`（`loadUiFontSizePx` / `applyUiFontSizePx` / `subscribeToUiFontSizeStorageChanges`，范围 12–20px，key `zcode-ui-font-size-px`）。

主题运行链路：

| 环节 | 文件 |
| --- | --- |

| --- | --- |
| 接口定义 | `packages/shared/src/platform.ts`（`IPlatformService`，含窗口 chrome、缩放、更新、CUA、浏览器 guest、telemetry 等分组方法；可选方法以 `?` 标注 Desktop-only） |
| 通道常量 | `packages/shared`（`PlatformChannels`、`InternalChannels`、`HostMessageTypes`）+ `packages/desktop/src/main/desktopMainIpc*.ts` 注册 |
| Desktop 实现 | `packages/desktop/src/renderer/src/desktopPlatform.ts`（`createDesktopPlatform`） |
| 暴露面 | `packages/desktop/src/preload/index.ts`（`contextBridge.exposeInMainWorld("zcode", {...})`，约 800 行，文件内注明集中暴露以便审计） |
| 业务服务 | 不经 preload，走 `MessagePort` + `@zcode/client` RPC：`connectViaMessagePort` → `IServiceAccessor` |
| 组件消费入口 | `packages/ui/src/hooks/usePlatform.tsx`（`PlatformProvider`）、`hooks/useServices.tsx`、`hooks/useWorkspaceServices.tsx` |

MessagePort 传递规则：`MessagePort` 不能经 `contextBridge`（会丢失原生方法），`preload` 用 `window.postMessage(..., [port])` transfer 到 renderer。

状态层：Zustand store 位于 `packages/ui/src/store/`。主要 store 与职责：

| store | 职责 |
| --- | --- |
| `StoreProvider.tsx` / `index.ts` | 应用级偏好（主题、语言、通知、界面模式） |
| `TabStoreProvider.tsx` / `tabStore.ts` | 窗口内 workspace / settings tab |
| `zcodeSessionStore*.ts` | 会话与任务状态（含 workspace slice、navigation、selectors） |
| `remoteWorkspaceSessionStore.ts` | 远程 workspace services 注册表 |
| `paneLayoutStore.ts`、`workbenchGroupStore.ts` | 分屏布局与 workbench 分组 |
| `taskQueryCacheStore.ts`、`commandsStore.ts`、`pluginStore.ts`、`skillStore.ts`、`mcpStore*.ts` | 各业务缓存与目录 |

约束（`AGENTS.md`）：广播同步字段（主题、语言）需防回环；UI 局部状态不得当作服务端事实；避免重复状态与多写入路径。

## 9. 国际化、快捷键与无障碍

- i18n：`packages/ui/src/i18n/IntlProvider.tsx`（`ZCodeIntlProvider`、`useZCodeIntl`），语言表 `locales/en-US.ts`、`locales/zh-CN.ts`；切换入口 `LocaleSwitcher.tsx`。语言变化经 `platform.setApplicationLocale()` 同步到 main 重建原生菜单（`src/main/desktopApplicationMenu.ts`）。
- 桌面菜单文案：`desktopMenuMessageIds` / `getDesktopMenuMessage`（`packages/shared`），`src/main/desktopWindowChrome.ts` 右键菜单与 `desktopApplicationMenu.ts` 均按其本地化。
- 快捷键：`packages/ui/src/shortcuts/`（绑定表和 `useShortcutCommandLabel`，tooltip 显示生效键位）；录制态经 `platform.setShortcutRecordingActive()` 让 main 摘除菜单 accelerator。
- 键盘总入口：`packages/ui/src/hooks/useAppKeyboard.ts`；默认按钮/焦点样式：`styles.css` 全局 focus reset + 组件局部 ring。
- 无障碍与对比度要求见 `DESIGN.md`「Accessibility and Internationalization」。
