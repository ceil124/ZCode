# 侧栏账户菜单改造指南

- 入口：`../README.md`。
- 结构与位置：`架构与文件地图.md`。
- 视觉取值规则：仓库根 `DESIGN.md`「Menus, Popovers, Dialogs」。

## 1. 定位

| 项 | 值 |
| --- | --- |
| 视觉位置 | 工作区侧栏最底部，头像 + 用户名 + 套餐徽标所在行；点击头像弹出 |
| 组件名 | `WorkspaceSidebarFooter` |
| 所在文件 | `packages/ui/src/WorkspaceSidebarFooter.tsx`（390 行） |
| 组件性质 | 不是独立「用户菜单」；登录/登出只是菜单中的两项 |

该 footer 同时复用于**工作区侧栏**与**设置页侧栏**，两处渲染同一份菜单，改动同时影响。

## 6. 动作链路

| 菜单项 | 回调（由挂载点注入） | 落点 |
| --- | --- | --- |
| 界面语言 | `onLocaleChange` → `WorkspaceSidebar.tsx:739` `handleLocaleChange` | `setLocalePreference`（store）；语言切换由 `i18n/IntlProvider` 应用，并经 `platform.setApplicationLocale()` 同步 main 重建原生菜单（`main/desktopApplicationMenu.ts`） |
| 界面主题 | `onThemeChange` → `WorkspaceSidebar.tsx:724` `handleThemeChange` | `setTheme`（`useTheme.ts` / store）→ `applyTheme()` 切 `html` 的 `dark` / `theme-zai-*` class；并触发 `root/useDesktopNativeThemeSync.ts` 同步原生标题栏 |
| 界面模式 | 组件内部直连 store：`setInterfaceMode(normalizeInterfaceMode(value))`（`:294–297`） | `store/StoreProvider` 的 `interfaceMode`；影响 `hooks/useInterfaceMode` |
| 界面缩放 | 组件内部：`platform.executeDesktopCommand(DesktopCommandIds.ZoomIn / ZoomOut / ResetZoom)`（`:179–184`） | main 侧 `desktopZoom.ts` + `main/index.ts` 命令处理；当前档位由 `platform.getDesktopZoomLevel()` 与 `onDesktopZoomLevelChanged()` 订阅（`:186–213`），范围 −3…5 |
| 使用统计 | `setPendingSettingsUsageIntent()` → `onUsageClick` | 侧栏传 `openSettingsTab`（`:365`）；设置页传 `handleOpenUsageSettings`。前者是导航意图（`lib/settingsNavigation.ts`），后者直接跳用量设置 |
| 升级 / 续期 | `onUpgradeClick` → `WorkspaceSidebar.tsx:758` `handleOpenCodingPlanUpgrade` → `openCodingPlanUpgrade({ providerId, funnelContext })` | 遥测上下文 `upgradeSource: "profile_menu"`、`eventRegion: "app.profile"`；label 可能被 `useCodingPlanEntryGate()` 的 `entryGate.label` 覆盖（`UsageSummary.tsx:431, 478`） |
| 连接使用 | `onLogin` | 由 `WorkspaceSidebar` / `Root` 注入，走 OAuth 流程 |
| 断开连接 | `onLogout` | 同上 |
| 齿轮按钮 | `onSettingsButtonClick` | 侧栏传 `openSettingsTab`；设置页传 `onBack`（配合 `settingsButtonMode="back"` 换文案） |

## 8. 改造注意

1. **两处共用**。改 `WorkspaceSidebarFooter.tsx` 会同时影响工作区侧栏与设置页；若只想改一侧，通过新增 props 或调用方 `className` 分流，不要在组件内硬编码场景判断。
2. **`isDesktop` 必须透传**。设置页曾因漏传导致缩放子菜单消失（源码 `SettingsPage.tsx:1545–1547` 有注释记录）。
3. **界面缩放仅桌面**。`:311` 的 `isDesktop ? ... : null` 是产品约束，Web / 手机远控不应出现该入口。
4. **升级入口始终显示**。产品要求常驻；未解析出当前套餐时由 provider family 决定品牌（`UsageSummary.tsx:453` 注释）。
5. **菜单内容用 `forceMount` 常挂载**（`:237`）。这是为了避免每次点开菜单都重建 footer 内部状态，改动菜单结构时不要移除。
6. **组件是 `memo`**。给 footer 传新 props 时注意引用稳定性，避免侧栏在会话流式渲染期间反复 commit。
7. **不要新增第二份缩放子菜单**。`:307–310` 注释记录了历史重复 bug 与固定分组顺序。
8. **改文案只动 locales**，不要在组件里硬编码中英文。
